Politique de confidentialité

Amusnaw — application d'apprentissage du kabyle, réalisée pour le Haut Commissariat à l'Amazighité (HCA). Dernière mise à jour : octobre 2026.

Données collectées

Compte : identifiant fourni par Google ou Apple (et, selon votre choix, votre prénom et votre adresse e-mail). Aucun mot de passe n'est stocké.

Apprentissage : vos conversations avec le prof, vos réponses aux exercices, les mots que vous avez appris, votre niveau et vos objectifs.

Réglages : langue d'explication, préférences de rappel. Les rappels quotidiens sont programmés sur votre téléphone.

Utilisation

Ces données servent uniquement à faire fonctionner l'application : adapter les leçons à votre niveau, suivre votre progression, et améliorer la qualité du prof. Les conversations peuvent être relues par des linguistes, de façon anonymisée, pour corriger le kabyle et entraîner les futures versions du modèle d'Amusnaw.

Aucune donnée n'est vendue ni utilisée à des fins publicitaires.

Hébergement

Les données sont hébergées sur un serveur situé en Algérie. Le modèle d'intelligence artificielle fonctionne sur ce même serveur : vos messages ne sont pas envoyés à un service d'IA tiers.

Vos droits

Vous pouvez supprimer votre compte et toutes vos données à tout moment depuis l'application : Réglages → Supprimer mon compte. La suppression est immédiate et définitive.
